AWS Cloud Hosting Architecture

How this local Digital Twin prototype scales to an enterprise AWS cloud production architecture:

Tier 1

Edge Ingestion

AWS IoT Core

  • MQTT broker ingests door optical counters & turnstiles.
  • Topic: vitc/auditorium/building024/telemetry
  • Mutual TLS authentication (X.509 certificates).
Tier 2

Stream Processing

Amazon Kinesis & Lambda

  • Kinesis Data Streams handles high-throughput tick stream.
  • AWS Lambda sanitizes, computes utilization %, and fires alert notifications (Amazon SNS) if occupancy > 80%.
Tier 3

Time-Series & State

Amazon Timestream & DynamoDB

  • Timestream stores sub-second time-series history for analytics.
  • DynamoDB stores venue configurations, building metadata, and current occupancy cache.
Tier 4

Spatial Digital Twin

AWS IoT TwinMaker

  • Binds 3D GLB model entities directly to Timestream component types.
  • Rule-based visual alarms when high threshold is breached.
Tier 5

Global Web Delivery

Amazon S3 + CloudFront

  • Static WebGL bundle and 20MB GLB asset served via CloudFront CDN.
  • WebSocket API Gateway provides live telemetry pushing to browser.
